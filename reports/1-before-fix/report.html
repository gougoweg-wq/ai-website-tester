How the tester found it

  2. Open /cart.html
  3. Compare the subtotal + shipping with the total

  "expected_total": 17.98,
  "confirmed_by_ai_review": "Total does not equal subtotal plus shipping"

🤖 AI explanation (pollinations (openai))

The cart shows a total of $22.97, which is $4.99 higher than the expected $17.98. Visitors will be confused and may question the pricing, potentially reducing trust and sales. The bug appears because the shipping cost is added twice to the subtotal when calculating the total.

Likely cause: The JavaScript calculation adds the shipping cost two times – once when setting the shipping element and again when computing the total. This double‑addition occurs because the script reads the shipping value from the DOM twice or mistakenly sums shipping with itself.

Suggested fix: Modify the calculation function so that it adds the shipping cost only once. Ensure the shipping element contains the correct value before totaling, and guard against duplicate adds.

```js
// Correct total calculation
const subtotalEl = document.getElementById('subtotal');
const shippingEl = document.getElementById('shipping');
const totalEl    = document.getElementById('total');

const subtotal = parseFloat(subtotalEl.textContent) || 0;
const shipping = parseFloat(shippingEl.textContent) || 4.99; // default flat fee

totalEl.textContent = (subtotal + shipping).toFixed(2);
```
